# Site font

LXGW WenKai GB Lite Regular, version 1.530.

- Upstream: https://github.com/lxgw/LxgwWenkaiGB-Lite
- Release: https://github.com/lxgw/LxgwWenkaiGB-Lite/releases/tag/v1.530
- Original file: LXGWWenKaiGBLite-Regular.ttf
- License: SIL Open Font License 1.1; the complete text is in OFL.txt.

The unmodified glyphs were converted to WOFF2 with FontTools 4.67.0 for web use. Unicode subsets let the browser download only the character groups needed by the homepage. Latin and frequently used Chinese characters have their own files; remaining CJK characters are grouped in blocks of 1,024 code points, with symbols and rare characters in a separate file. The ranges in ../../css/fonts.css determine which files load.

Site navigation, headings, body text, dates, counters and the homepage slug use this font. Code and keyboard shortcut labels retain their monospace font stacks.
